# 給与計算 (PayrollCalculator)

macOS標準のカレンダーアプリと連携し、バイトのシフトから給与を自動計算するネイティブMacアプリです。

## 機能

- **カレンダー連動**: カレンダーアプリのイベントを自動読み込み（EventKit）
- **カテゴリ選択**: バイトのカレンダーを複数選択可能
- **月次給与計算**: 年月を選ぶだけで該当月のシフトを集計
- **給与条件**: 時給・休憩時間（1シフトあたり）・交通費（1出勤日あたり）
- **深夜割増**: 22:00〜翌5:00の労働に割増（25/30/35/50%）を自動加算
- **CSV書き出し**: 給与明細をExcel対応のUTF-8 (BOM付き) で保存
- **設定の永続化**: 設定は自動保存されます

## 使い方

```bash
./build.sh          # ビルド（build/PayrollCalculator.app を生成）
open build/PayrollCalculator.app
```

1. 初回起動時にカレンダーへのアクセスを求められたら「許可」
2. 「設定」タブでバイトのカレンダリーにチェックを入れ、時給などを入力
3. 「給与計算」タブで年月を選ぶと自動計算されます

> カレンダー許可を拒否した場合は、システム設定 ＞ プライバシーとセキュリティ ＞ カレンダー から許可してください。

## 計算方法

| 項目 | 計算 |
|---|---|
| 実働時間 | (終了 − 開始) − 休憩時間 |
| 基本給 | 時給 × 実働時間 |
| 深夜割増 | 時給 × 深夜帯(22:00〜翌5:00)実働時間 × 割増率 |
| 交通費 | 出勤日数 × 交通費/日 |
| 合計 | 基本給 ＋ 深夜割増 ＋ 交通費 |

## ファイル構成

```
payroll/
├── Sources/
│   ├── PayrollApp.swift        # アプリのエントリポイント
│   ├── CalendarManager.swift   # EventKit連携・給与計算ロジック・CSV出力
│   └── ContentView.swift       # UI（給与計算タブ / 設定タブ）
├── Info.plist                  # バンドル設定・カレンダー利用説明
└── build.sh                    # ビルドスクリプト
```

## 要件

- macOS 14 Sonoma 以降
- Xcode Command Line Tools（swiftc）
